# 当前公开 API

认证使用 HttpOnly、SameSite=Strict cookie，生产设置 Secure。所有状态修改检查来源；用户资源按登录身份授权。API 错误为 HTTP 状态码及 detail，版本冲突返回409。服务端负责判分，未提交题目的响应不包含正确答案和解析。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | /api/register、/api/login、/api/logout | 用户名注册与登录退出 |
| GET | /api/me | 身份与强制改密状态 |
| POST | /api/password | 验证原密码、更改密码、撤销旧登录 |
| GET | /api/users | 管理员列出账号 |
| POST | /api/users/{id}/reset | 管理员重置并强制改密 |
| POST | /api/users/{id}/disable | 管理员停用普通用户、撤销其全部登录，保留个人记录；重复停用幂等 |
| DELETE | /api/users/{id} | 仅管理员，必须提交 `{confirm: true}`；原子删除普通用户账号、全部登录、个人练习与历史、错题和收藏；不存在时幂等成功，管理员账号返回 400 |
| GET/POST | /api/banks | 查询可见题库 / 管理员创建 |
| PATCH | /api/banks/{id} | 管理员修改名称或下架，带 revision |
| GET | /api/template.csv、/api/template.xlsx | 下载管理员模板 |
| POST | /api/banks/{id}/preview | multipart 文件，全量校验及预览 |
| POST | /api/imports/{id}/commit | 校验预览版本并原子合并；可选 `{publish: true}` 直接生效，默认保存草稿，同方式重复确认幂等、改换方式返回 409 |
| POST | /api/banks/{id}/publish | 带 revision 发布草稿 |
| POST | /api/banks/{id}/archive | 带 revision 与 question_id 保存归档草稿 |
| GET/POST | /api/sessions | 个人会话历史 / 发起新会话 |
| GET/PATCH | /api/sessions/{id} | 查询 / 保存 index、selected、revision |
| POST | /api/sessions/{id}/answer | 按 index、selected、revision 服务端判分；相同答案重复提交幂等 |
| POST | /api/sessions/{id}/finish | 带 revision 结束，不提交未答题 |
| GET | /api/learning | 个人错题、收藏、派生统计 |
| POST | /api/favorite、/api/mastered | question_id 与 value，修改个人状态 |
| GET/POST | /api/reports | 按权限读取 / 已答题反馈 |
| PATCH | /api/reports/{id} | 管理员处理状态 |

完整字段契约可在运行中的 /docs 查看。SQLite 事务串行化版本校验和写入；相同会话的旧版本不会静默覆盖新版本。后台资源不会向普通用户返回草稿或题库答案。管理员不是学习记录的代理身份，不能通过会话 ID 查看其他用户会话。

彻底删除账号会保留公共题库及其他用户数据；该用户的题目纠错保留，提交者 `user_id` 置为 `null` 并清除所有者关联。操作审计保留历史标识，不作为账号外键。上述变更及删除审计在同一事务提交，失败完整回滚。删除后所有旧登录失效，原凭证不能登录；重新注册同名账号会获得新的账号标识及空学习记录。

注册请求仅需 `{username, name, password}`：用户名 3–32 位字母、数字或下划线（大小写不敏感且唯一）；姓名去除首尾空白后 1–50 字符；密码沿用 10–128 字符规则。注册无需审批，不能由请求指定管理员身份。

登录、`/api/me` 和管理员用户列表返回 `id, username, nickname, role, must_change, name, created_at, disabled`，不返回密码或哈希。`created_at` 为注册时的 Unix 秒时间戳；旧账号 `name/created_at` 为 `null`，界面明确显示未知；保留旧昵称和学习记录。停用账号新登录返回 403；已有登录已撤销，访问受保护接口返回 401。即使登录记录存在，鉴权仍会检查停用状态。管理员账号不能停用，普通用户不能列出或停用账号。


## 核对方式
创建练习可传 `review_mode`：`immediate`（默认，单题提交）或 `deferred`（先保存全部选择）。`POST /api/sessions/{sid}/review` 接收 `revision`，仅在统一核对练习的所有题目已有选择时提交整场。核对在单事务内进行，重复成功请求返回已核对状态；未完成返回 400、版本冲突返回 409。统一核对前 `/answer` 不接受提交，正确答案和解析不返回。


## 年份、备考项目与题库归属（第 01 项）

以下目录接口仅管理员可用；普通用户返回 403，未登录返回 401。

| 方法 | 路径 | 请求与行为 |
| --- | --- | --- |
| GET | /api/directories | 返回 `years`、`projects`；项目含 `year_id` |
| POST | /api/years | `{name}` 新建年份，返回 `{id,name}` |
| PATCH | /api/years/{id} | `{name}` 改名年份 |
| DELETE | /api/years/{id} | 仅无项目时删除，否则 409 |
| POST | /api/projects | `{name,year_id}` 新建备考项目 |
| PATCH | /api/projects/{id} | `{name}` 改名备考项目 |
| DELETE | /api/projects/{id} | 仅无任何关联题库时删除，否则 409；下架、归档状态也阻止删除 |

名称须为去除两端空白后 1–100 字符的字符串。归属须为存在的年份／项目 ID；类型不合法返回 400，不存在返回 404。
`POST /api/banks` 可传 `project_id`；`PATCH /api/banks/{id}` 可用 `{revision,project_id}` 调整归属（冲突返回 409）。年份通过项目关联推导，不接受独立的题库年份，避免年份与项目不一致。移动只改变归属和题库 revision，不改变题库 ID、题目、草稿、练习及个人记录。
为兼容旧题库，未传 `project_id` 的旧创建方式继续可用，旧数据无需回填；新管理页面创建题库要求选择项目，未分配题库在待整理入口管理。第 05 项起，未分配题库不向学习者展示。

2026-10-21 后续确认：`DELETE /api/projects/{id}` 可传 `{confirm_delete_banks:true}`，原子删除项目及其中全部题库（含草稿、归档题库）和导入预览。非空项目未明确确认仍返回 409；仅管理员可调用。保留全部个人练习、历史、错题、收藏和项目快照，已有练习可继续，已删除题库新建练习返回 404。没有会话快照的既有个人收藏保存已发布内容以供回看；不保留或暴露题库草稿。年份删除规则不变。本条取代上表“项目仅能为空时删除”及旧文档不提供题库彻底删除的限制；界面通过项目删除统一操作，不增加单独题库删除入口。


## 按目录选择练习（第 02 项）

`GET /api/learning/directories` 向已登录用户返回 `years`、`projects`，仅包含有已发布题库的项目及其年份；不暴露仅有私有草稿的目录。目录写入和管理查询仍使用管理员接口，权限不变。

普通用户的 `GET /api/banks` 摘要包含 `project_id`，保留 `count`、`categories`，不返回题目、答案或草稿。第 05 项起仅返回已分配且已发布的题库。知识分类只在所属题库内生效；空分类允许导入，全部无分类时前端隐藏分类筛选。

`POST /api/sessions` 继续接收一个 `bank_id`、可选 `category`（空为全部）、`mode`（顺序练习／随机练习／错题练习／收藏练习），保留原有 `amount`、`restart`、`review_mode`。空范围返回 400 且不创建会话，错题、收藏和历史按登录用户隔离。

首页按年份→备考项目→题库选择；切换上级清空下级。本机按用户 ID 保存目录、题库、分类和练习方式，刷新及重新登录可恢复，失效后明确提示并等待重新选择，不自动替换题库。记忆选择属于当前浏览器；已有练习的进度继续由服务端跨设备同步。


### 导入确认（任务 03）

项目内新建题库后上传模板，或选择已有题库更新。CSV 与 XLSX 共用整批校验；预览返回 `questions`、`errors`（行与字段）、`added`、`updated`。题目编号只匹配所属题库，文件缺失的旧题保留；分类允许空值。

`POST /api/imports/{id}/commit` 无请求体或 `{ "publish": false }` 保存草稿，`{ "publish": true }` 合并并立即生效。两种方式均要求管理员、有效预览和一致的题库版本；合并、发布及确认标记在同一事务提交。直接生效会包含该题库已存在的未发布草稿，预览计数以当前草稿为基准；页面会在上传前提示。重复相同方式确认不再写入，改变已确认方式返回 409；草稿稍后通过题库发布接口发布。更新不改写已有会话中的题目快照或历史成绩。

### 归档题库与隐藏项目（任务 04）

管理员 `PATCH /api/banks/{id}` 接受 `{revision,status:"archived"}`，即刻归档整个题库，不删除题目或草稿；版本冲突返回 409。原 `POST /api/banks/{id}/archive` 仍表示单题归档草稿。管理页面提供“归档题库”，不提供题库彻底删除。归档题库从学习者可选题库与学习目录移除；`POST /api/sessions` 对四种方式一律拒绝新建（400），已有练习仍可继续作答和结束。

管理员 `PATCH /api/projects/{id}` 可传 `{hidden:true}` 隐藏、`{hidden:false}` 恢复，也可与 `name` 同时更新；隐藏字段必须为布尔值。隐藏仅控制页面默认收起，管理和学习目录接口保留该字段，页面通过“显示已隐藏项目”找回。隐藏不改变题库发布状态，不禁止发起练习，不清理个人记录。存在归档题库的项目及其年份仍禁止删除。

新建会话保存 `project` 归属快照（项目 ID、名称、年份 ID、名称），历史列表附带该归属。旧会话在题库首次分配归属时补充快照；已有归属的旧会话在题库移动或年份、项目改名前固定快照，避免历史随目录变动。`GET /api/learning` 的 `records` 按题目 ID 提供本人练习快照、原会话 ID、题目位置、题库标题和项目归属，供错题、收藏回看。练习快照答案及解析仅在已提交作答时返回，与会话接口一致。没有练习快照的本人收藏从题库已发布内容补充题目、答案和解析（不读取草稿），其 `session_id`、`index` 为 `null`，前端不展示原练习入口；归档不抹去记录，也不授予跨用户读取权限。

### 旧题库安全迁移（任务 05）

缺少或为空的 `project_id` 表示待整理，不根据标题推断目录，不复制或重写旧对象。管理员使用既有待整理入口及 `{revision,project_id}` 分配归属；分配只修改归属和 revision，保留原发布状态及未发布草稿。

待整理题库不进入普通用户题库列表、学习目录、可练习题数；四种方式（含管理员直接请求）新建练习均返回 400。已有会话继续按本人权限读取、保存、作答和结束，历史、错题和收藏仍可回看；拥有题目快照者可以继续收藏该题，其他用户不能用待整理题目 ID 越权收藏。分配后仅原本已发布的题库进入用户目录，草稿、下架和归档状态不会自动发布。备份恢复步骤及验证见 [迁移验收](legacy-migration-verification.md)。


### 可选限时练习（任务 06）

四种练习方式共用 `POST /api/sessions` 的可选 `duration_minutes`：整数 1–1440；省略或 `null` 为不限时。字符串、布尔值、小数及超范围值返回 400。不改变已有不限时会话。

限时会话持久化 `deadline`（Unix 秒），为创建时间加分钟数；创建、读取及写入成功响应附带 `server_now`，客户端用服务端时间锚点显示倒计时，不依赖设备墙钟。截止时间只在创建时确定，刷新、离开或换设备不会重置。

读取会话和历史列表时，服务端在事务内按 `now >= deadline` 结算到期状态：设置 `ended=true`、`ended_at=deadline`，revision 仅增加一次。无人在线时无需后台浏览器执行交卷，下一次读取或写入请求即得到确定结果。读取历史后到期会话不再出现在“继续练习”。

到期或提前结束的限时会话拒绝草稿保存、单题提交和统一核对，返回 `409 {detail,session}`；其中 `session` 为本人会话结果且保持既有答案隐私。拒绝响应仍提交到期状态，避免异常回滚。`POST /api/sessions/{id}/finish` 对已结束会话幂等返回结果，不要求旧设备刷新 revision；未结束时仍校验 revision。SQLite 写事务串行保证两设备不重复计分。

已提交题计入结果，未提交题算未答；服务器草稿保留供回看但不会自动提交，前端到期后清除本机待同步选择。统一核对模式到期前必须显式核对才能计分，超时不能将草稿转成答案。页面定期读取状态，在停留、返回页面或恢复网络时展示结果；断网时最终成绩以重新连接后的服务端状态为准。
