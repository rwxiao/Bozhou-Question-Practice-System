# 亳州网络部在线刷题：通用在线刷题网站

本版为具有服务端认证、持久化数据库与跨设备状态的单服务器应用。管理员统一创建、导入及发布公共题库；普通用户自主注册用户名与密码，仅管理自己的练习记录。完整需求以本地规格为准。

## 页面与交互

用户选定 B 的顶部导航与 A 的学习工作台答题区域。桌面使用学习导航、题目、答题卡三栏；手机改为纵向布局及紧凑导航。提交或下一题按钮位于选项下方独立全宽首行，上一题和结束练习在次行，不存在原型切换条。

工作台显示继续练习、累计作答、正确率、覆盖率、待复习错题。支持顺序、随机、错题、收藏四种模式及 10/20/50/全部题量；顺序保存接续位置，随机场内不重复。提交锁定答案并显示解析，未提交题目不计分。

## 内容与数据

CSV/XLSX 固定模板，纯文字单选、多选、判断题，A–D 选项，多选答案及标签以 | 分隔。导入整批校验、预览前10题、保存草稿、人工发布。题库内编号稳定；新编号新增，同编号更新，缺少的旧题保留。

服务器保存会话草稿与题目快照；版本检查拒绝过时写入，本机保留未同步选择。下架与归档禁止新练习，已有会话和历史保留。正确答案发布变化后，已有已掌握错题恢复待复习。

账号采用密码哈希及服务端会话 cookie。密码重置由管理员站外确认身份后进行，重置使旧登录失效并要求修改临时密码，不使用邮箱。

## 运行边界

FastAPI、SQLite 和 React/shadcn 前端；适用于单应用实例。Docker Compose 包含应用、Caddy HTTPS 代理和每日备份服务。正式域名、Docker 运行及真实手机部署验收尚未执行，见验证记录。旧截图及旧浏览器脚本来自历史设计，不作为本版通过证据。


## 部门品牌与新版组件布局

品牌统一为“亳州网络部在线刷题”。导航分为品牌与账号操作行、功能导航行；工作台使用统计概览、继续练习与练习设置分区。桌面答题使用题目与答题卡，宽屏附学习导航；小屏答题卡置于题目前。登录页采用部门介绍与登录表单双栏，小屏纵向排列。

组件使用 shadcn/ui 官方 CLI 安装的 Radix 版本。表单采用 FieldGroup/Field，答案采用 ToggleGroup，弹窗采用 Dialog，状态采用 Badge/Alert，管理数据使用 Table。配色通过语义主题变量配置，提交按钮仍为选项下方独立全宽首行。
