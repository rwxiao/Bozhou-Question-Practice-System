## 实现与范围

首页使用年份→备考项目→单个题库的下拉选择，切换上级清空下级。默认全部知识分类；分类允许为空，整个题库无分类时隐藏筛选。顺序、随机、错题、收藏四种方式复用原有会话 API、答案解析、进度同步和历史快照。

目录、题库、分类与练习方式按用户 ID 记在当前浏览器，刷新可恢复。保存选择失效时清空不匹配部分并提示重新选择，不自动切换题库。已有会话进度仍由服务端跨设备同步。我的学习集中提供错题、收藏和历史入口，并保留次要纠错反馈入口。

新增只读学习目录接口仅返回含已发布题库的目录，管理员目录接口及写权限不变。题库摘要增加 project_id，不暴露草稿或答案。第 05 项迁移前保留未分配题库的兼容选择；第 03–08 项及部署不在范围内。
