# 第 04 项：归档题库与隐藏项目验收

2026-10-21。用户确认公开 HTTP API 集成测试、浏览器流程及前端检查的测试边界。

## 实现

管理列表支持归档整个题库，不提供题库彻底删除。归档即时生效，学习者不能从顺序、随机、错题、收藏任一方式新建练习；已有练习、成绩、错题、收藏及目录关联保留。

项目可隐藏、取消隐藏；管理员及学习者默认收起，通过“显示已隐藏项目”找回，手机下拉与旧题库入口遵守相同规则。隐藏不改变题库发布状态或个人记录。新练习保存项目／年份归属快照，旧练习无快照时兼容使用题库当前归属。我的学习支持展开错题、收藏的原题快照并打开原练习，仅已作答快照展示答案与解析。
