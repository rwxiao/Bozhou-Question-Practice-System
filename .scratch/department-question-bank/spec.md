# 部门题库管理与练习流程简化：正式规格

Status: open
Triage: ready-for-agent
Date: 2026-10-21
Review: 依据完整访谈整理；测试边界待确认，尚未开始实施

## Problem Statement

现有网站的题库管理和导入发布流程繁琐，无法清晰管理不同年份、比赛和考试的多个题库。管理员需要便捷地上传、更新和整理题库；备考人员需要快速选题、自主练习，并在题库归档后保留已有练习和历史。

## Solution

基于现有网站增量改造，按“年份 → 备考项目 → 多个题库”管理内容，题库内部可按知识分类筛选。上传 Excel、CSV 后自动检查并预览，可直接确认生效或保存草稿。用户自主注册和练习，支持四种练习方式及可选限时。通过归档、隐藏、停用和账号删除整理内容与人员，保持桌面和手机界面简洁。

## Implementation Decisions

### 目录与生命周期

- 增量扩展现有服务端、数据库和前端，不重写整个网站。新增年份、备考项目及题库归属；一个项目属于一个年份，一个已整理题库属于一个项目。
- 专业暂体现在题库名称中；知识分类复用现有题目分类能力，属于题库内部筛选维度。
- 年份或项目存在关联内容时不能删除，已归档题库也算关联；年份下存在项目也不属于空目录。服务端负责校验，不能仅隐藏按钮。
- 项目隐藏表示整理展示，题库归档表示停止新练习，两者不能混为一谈。
- 归档后不出现在可选题库中，任何练习方式均不能新建会话；已有会话可完成，历史、错题和收藏可回看。

### 导入发布

- 复用模板解析、整批校验、预览及按编号合并能力；预览后提供直接生效和保存草稿两条路径。
- 直接生效仍需权限、校验、版本冲突检查和原子写入，不能绕过现有一致性约束；草稿不改变已生效内容。
- 题目编号只在所属题库内用于更新匹配，缺失旧题保留；确认前显示题数、少量样题、新增和修改数量。
- 沿用题目快照，不能因发布新版本改写进行中会话和历史结果。

### 练习与计时

- 一次选择一个题库，默认全部知识分类，也可筛选一类；保存上次选择并提供继续入口。
- 顺序、随机、错题、收藏为练习方式，限时为可叠加设置。
- 服务端保存统一截止时间并判定到期；客户端显示倒计时，刷新、离开或换设备不重置时间。
- 到期后不接受新作答，结束操作应幂等；已提交题计入结果，未提交题算未答。无人在线时不依赖浏览器后台计时器，返回或相关请求时仍须呈现正确结果。
- 保留现有不冲突的答案解析、学习记录和跨设备进度能力，不擅自修改既有其他答题模式。

### 人员与页面

- 自助注册用户名、姓名、密码；补充注册时间和账号停用状态。旧账号未知真实注册时间不得伪造。
- 管理员可看注册信息并停用或删除账号，不提供个人成绩监管；停用须阻止已有登录继续访问受保护功能。
- 删除账号须有明确影响提示及服务端权限校验；保留普通用户仅能访问本人记录的权限边界。
- 用户首页负责选择题库和继续练习，我的学习负责错题、收藏、历史。
- 管理首页桌面左侧年份项目、右侧题库列表，突出上传、更新、归档；用户管理独立，纠错为次要入口。手机目录改为下拉选择。
- 旧题库进入仅管理员可见的待整理区域，分配年份、项目后再向用户展示；保留题目和个人记录关联，不猜测旧题库归属。

## Testing Decisions

- 主要边界为现有服务端公开 HTTP API 集成测试，复用隔离数据库和多客户端会话，测试外部行为、权限和可观察结果，不逐函数模拟实现。
- 现有同类测试已覆盖注册权限、原子导入、草稿隐私、Excel 预览冲突、更新保留缺失题、历史快照、跨设备冲突及错题收藏隔离；优先扩展这些测试，不另建重复体系。
- 目录覆盖新建改名、题库移动、分类隔离、空目录删除及归档题库阻止删除。
- 导入覆盖直接生效和草稿两条路径、新增修改数量、错误整批不生效、预览过期冲突及缺失题保留。
- 归档和迁移覆盖禁止新练习、已有会话继续、历史及错题收藏可查，以及迁移前后数量和稳定关联核对。
- 限时在公开接口边界控制时间，覆盖四种方式、截止前后、离开返回、跨设备、重复结束、超时提交；避免实际长时间等待。
- 人员覆盖自主注册、列表字段、普通用户越权、停用已有会话、删除影响及其他用户数据隔离。
- 浏览器仅补充 API 无法证明的桌面和手机布局、导入主流程、草稿选择、倒计时及继续入口。旧截图和旧浏览器脚本不作为本次通过证据。
- 执行现有前端类型检查和构建；暂不引入组件或内部函数测试边界。
- 以上测试边界为提案：公开 API 为主，少量浏览器验收为辅，待用户确认；未声称已经执行。

## Out of Scope

- 从零重写、多部门组织体系或注册审核。
- 管理员组织正式考试、统一交卷、统一计时或查看个人成绩。
- 专业独立目录、无限目录层级和跨题库混合抽题。
- Word、PDF、图片及任意文件自动识别导入。
- 更新文件缺失题即删除旧题的全量替换语义。
- 题库彻底删除；本次采用归档。
- 本轮未要求的新题型、排行榜等扩展功能。
- 实际部署发布；本次请求仅生成本地规格。
