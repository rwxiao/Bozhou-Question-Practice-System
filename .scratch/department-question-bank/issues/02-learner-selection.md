# 02：按目录选题与个人学习入口

Status: resolved
Triage: ready-for-agent
Blocked by: 01

## What to build

备考人员从首页按年份、项目选择一个题库，按知识分类和练习方式开始练习，或直接继续已有练习；在我的学习中集中访问错题、收藏和历史。

## Acceptance criteria

- [x] 年份、项目、题库选择联动；切换上级清除不匹配的下级选择，一次练习只选一个题库。
- [x] 默认全部知识分类，也可选其中一类，例如 AI 知识或安全知识；不同题库的同名分类不混题。
- [x] 可选择顺序、随机、错题、收藏四种方式；空题库或没有符合条件题目时明确提示，不建立无效练习。
- [x] 记住上次选择；选择失效时可恢复选择其他题库，不自动跳入错误题库。
- [x] 首页提供继续练习，保留现有进度同步、答案解析和历史快照行为。
- [x] 我的学习可进入错题、收藏、历史，保留次要纠错反馈入口。
- [x] 手机使用下拉目录，桌面和手机均可完成选择、开始及继续流程。
- [x] 通过公开 API 验证筛选、练习方式及个人记录隔离，通过必要浏览器验收验证入口与记忆选择；完成类型检查和构建。
