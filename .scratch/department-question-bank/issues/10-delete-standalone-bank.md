# 10：独立删除题库

Status: resolved

## 用户确认

2026-10-21：补充未分配项目的题库也可删除，无需创建项目。沿用删除项目时已确认的个人记录保留规则。

## 实现

每个题库卡片提供“删除题库”，确认提示名称、不可撤销性和个人记录保留范围。管理员接口要求明确确认和题库 revision，拒绝越权及过期操作。单库删除与项目删除复用同一事务清理逻辑，删除关联导入预览，保留会话、成绩、错题、收藏和旧项目快照。未分配旧会话显式保存空项目快照，避免删库后历史查询依赖不存在的题库。

## 验证

新增已分配/未分配题库的公开 API 回归用例；覆盖权限、确认、版本冲突、归档题库删除、历史读取、继续作答、无会话收藏回看及禁止新练习。旧测试“不支持 DELETE 题库”断言更新为“无确认时拒绝”。Edge 隔离浏览器已验证独立题库删除入口；未删除用户本地题库。前端类型检查、构建通过。

最终复核：64 项全量测试、后端严格类型检查、前端类型检查和构建通过；Edge 隔离浏览器通过。Standards 与 Spec 独立审查均为 0 项剩余发现。详见 [十项任务最终核验](../../../docs/ten-tickets-verification.md)。
