# 08：带影响提示的账号彻底删除

Status: resolved
Triage: ready-for-agent
Blocked by: 07

## What to build

管理员在用户管理中看到删除账号的明确影响，确认后彻底删除目标账号，旧登录失效，并依照已明确的数据清理规则处理关联记录。

## Acceptance criteria

- [x] 实施前明确并记录关联数据清理范围，确认提示准确列出实际影响；不得先实现破坏性默认再补确认。
- [x] 管理员可选择目标普通用户并明确确认删除，普通用户及绕过界面的未授权请求均被拒绝。
- [x] 删除后账号不可登录，既有登录访问受保护功能失效。
- [x] 按确认的规则原子处理个人记录和关联数据，不产生悬空引用；失败不会留下部分删除状态。
- [x] 公共题库及其他用户账号和记录不受影响，重复删除请求不造成额外损害。
- [x] 保留账号停用作为无需清除记录的常用操作；不扩展为管理员账号删除功能。
- [x] API 测试覆盖权限、旧登录、数据范围、其他用户隔离及失败一致性；浏览器验证提示和确认流程，完成前端检查。

## 已确认数据清理与测试范围

- 2026-10-21 用户确认：删除普通用户账号、全部登录凭证、个人练习与历史、错题和收藏；保留公共题库和其他用户数据、停用功能，禁止删除管理员。
- 纠错内容保留并移除提交者关联；审计保留历史标识（非外键）。所有处理在同一事务完成。
- 用户确认测试边界：HTTP API 集成测试为主，浏览器验证提示及确认流程，执行前端类型检查和构建。
