# 05：旧题库待整理与安全迁移

Status: resolved
Triage: ready-for-agent
Blocked by: 01, 02

## What to build

管理员在仅自己可见的待整理区域找到旧题库，分配年份、项目后向用户展示；迁移过程不丢失既有练习和个人记录。

## Acceptance criteria

- [x] 使用有旧题库、进行中练习、历史、错题及收藏的代表性旧数据完成迁移验证。
- [x] 旧题库先进入管理员可见的待整理区域，不根据标题猜测年份或项目。
- [x] 管理员可为旧题库分配归属，符合既有生效状态的题库随后在用户目录可见；不能把旧草稿意外发布。
- [x] 保留题库和题目稳定标识、会话快照、练习状态、历史、错题和收藏关联。
- [x] 迁移重复运行或服务重启不重复创建、不重复迁移、不丢失已整理结果。
- [x] 迁移前后核对数据数量及关联，记录备份和恢复验证办法；本任务不直接操作生产数据或部署。
- [x] API 验证权限、分配前后展示及个人记录；浏览器验证待整理到分配归属的完整操作，完成前端检查。

## 已确认细节

- 2026-10-21：用户确认待整理题库禁止新练习、允许继续已有练习。

## Comments

- 2026-10-21：用户确认任务拆分；本切片不依赖导入重构或归档功能完成。

- 2026-10-21：用户确认待整理题库禁止新建练习、允许继续已有练习；确认公开 HTTP API、少量浏览器验收及迁移数量关联核对的测试边界。

## Answer

旧题库无需重写即可进入管理员待整理区域；统一限制未分配题库的用户可见性、新练习、学习统计和收藏权限。管理员沿用既有归属分配流程，保留原生效状态、稳定标识、快照和个人记录。重复启动及分配后的再次启动不改变已有数据。

31 项测试、mypy、前端类型检查与构建、桌面／手机浏览器验收通过；隔离备份恢复和逐行数据核对通过。Standards、Spec 双轴独立审查各 0 项发现。备份恢复步骤及证据见 [迁移验收](../../../docs/legacy-migration-verification.md)。未操作生产数据，未部署。
