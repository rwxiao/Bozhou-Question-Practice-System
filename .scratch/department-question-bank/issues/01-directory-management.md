# 01：年份、项目与题库归属管理

Status: resolved
Triage: ready-for-agent
Blocked by: None

## What to build

管理员按年份建立备考项目，在项目下创建多个题库，改名目录并调整题库归属。管理首页桌面左侧目录、右侧题库列表，手机使用下拉选择。本切片包含完整持久化、公开接口、权限、页面及验证，不单独交付空数据结构。

## Acceptance criteria

- [x] 管理员可新建、改名年份和项目；每个项目属于一个年份，一个已整理题库属于一个项目。
- [x] 项目下可创建多个题库，已有题库可移动到其他年份、项目，题目和个人记录关联不变。
- [x] 专业暂通过题库名称表达，不新增独立层级。
- [x] 只有完全空的目录可删除；年份下有项目、项目下有任意题库（包括归档题库）均拒绝删除，服务端也执行限制。
- [x] 管理首页呈现左目录右列表及手机下拉入口，刷新后数据保留。
- [x] 普通用户无法调用目录管理功能；拒绝不存在或不合法的归属。
- [x] 扩展现有公开 API 集成测试验证上述行为，补充必要桌面、手机操作验收及前端类型检查、构建。
- [x] 为后续迁移保留旧题库稳定标识和未分配归属的兼容能力，不在本切片猜测旧题库年份或破坏原有学习记录。
