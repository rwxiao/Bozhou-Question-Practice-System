# 07：姓名注册、用户列表与账号停用

Status: resolved
Triage: ready-for-agent
Blocked by: None

## What to build

用户通过用户名、姓名、密码自主注册，管理员在独立用户管理页查看注册信息并停用账号，个人学习记录继续保留。

## Acceptance criteria

- [x] 注册仅要求用户名、姓名、密码，无审批，保留用户名唯一与现有密码安全规则。
- [x] 用户管理独立页面展示用户名、姓名、注册时间，不展示明文密码，不新增个人成绩监管。
- [x] 新账号记录真实注册时间，旧账号未知注册时间明确表示未知，不伪造为迁移时间。
- [x] 姓名字段迁移兼容现有账号，旧账号仍可登录并保留个人记录。
- [x] 管理员可停用普通用户账号，停用后新登录和既有登录访问受保护功能均被服务端拒绝。
- [x] 停用保留个人练习、历史、错题、收藏；普通用户不能查看用户列表或停用他人。
- [x] API 测试覆盖注册、字段、越权、已有登录失效和记录保留；浏览器验证注册及用户管理，完成前端检查。
