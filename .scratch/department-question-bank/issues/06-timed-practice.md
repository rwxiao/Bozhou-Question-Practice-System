# 06：四种练习方式的可选限时

Status: resolved
Triage: ready-for-agent
Blocked by: 02

## What to build

备考人员选择顺序、随机、错题或收藏后，可自行填写练习分钟数；离开或换设备继续计时，到时自动结束并展示结果。

## Acceptance criteria

- [x] 四种练习方式均可开启或关闭限时，时长输入校验清晰，非限时练习保留原行为。
- [x] 服务端持久化统一截止时间，客户端显示倒计时；刷新、离开、换设备不重置时间。
- [x] 到期后服务端拒绝作答并结束会话；客户端停留、关闭后返回或另一设备访问都获得正确结果。
- [x] 已提交题计入结果，未提交题算未答；到期后的草稿选择不能悄悄转成已提交答案。
- [x] 重复结束、两设备同时提交及到期边界不重复计分，不改写已结束结果。
- [x] 无人在线时不依赖浏览器后台定时器保证正确性；已有不限时会话保持兼容。
- [x] 在现有公开 API 测试边界控制时间，验证截止前后、四种方式、两设备、离开返回及幂等；浏览器验收倒计时和结果，完成前端检查。

## Comments

- 2026-10-21：用户确认任务拆分。限时为个人练习设置，不引入管理员统一考试功能。

- 2026-10-21：完成可选限时、服务端截止及到期结算、前端倒计时与结果。测试边界沿用本任务验收标准指定的公开 HTTP API 和浏览器；全套 50 项测试及前端检查通过，独立双轴审查发现已修复并复核。详见 [验收记录](../../../docs/timed-practice-verification.md)。

## Answer

四种练习方式均支持可选限时；截止时间持久化且跨设备一致，服务端在相关请求中结算到期，不依赖浏览器后台运行。只统计显式提交答案，超时草稿保持未答，重复结束和并发请求不会重复计分或改写结果。API 契约见 [docs/api.md](../../../docs/api.md)，复现脚本与证据见验收记录。
