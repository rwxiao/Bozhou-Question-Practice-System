## Acceptance criteria

- [x] 管理列表提供归档入口，不提供本次未授权的题库彻底删除。
- [x] 归档题库不出现在可选列表，服务端拒绝顺序、随机、错题、收藏方式从该题库发起新练习，包括绕过界面直接请求。

- [x] 已结束项目可隐藏，默认收起，并有方式找到；历史记录保留所属项目。
- [x] 项目隐藏与题库归档行为区分，不因隐藏意外删除内容或改变个人记录。
- [x] 关联归档题库的目录仍禁止删除。
- [x] API 集成测试覆盖生命周期及历史保留，浏览器验证管理员归档、隐藏与用户回看流程，完成前端检查。
