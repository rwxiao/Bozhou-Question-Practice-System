# 03：简化题库导入与更新

Status: resolved
Triage: ready-for-agent
Blocked by: 01

## What to build

管理员找到项目后上传 Excel 或 CSV，检查结果并预览，一次确认生效或保存草稿；可新建题库，也可按题目编号更新已有题库。

## Acceptance criteria

- [x] 项目内区分新建与更新入口，提供 Excel、CSV 模板下载，知识分类使用现有分类能力。
- [x] 上传自动校验，错误定位具体行和字段；失败整批不写入生效内容。
- [x] 校验通过显示题数、少量样题以及新增和修改数量。
- [x] 可直接确认导入并生效，不强制先存草稿再另行发布；也可保存草稿并稍后发布。
- [x] 草稿未发布时不影响用户可用内容；直接生效保留权限、预览版本冲突与原子写入约束。
- [x] 在同一题库内按稳定题目编号新增或修改；文件缺失的旧题保留，不同题库相同编号互不覆盖。
- [x] 发布更新不改写已有练习和历史成绩，重复或过期确认不造成错误更新。
- [x] 公开 API 测试覆盖两条路径、Excel/CSV、失败整批不生效、计数、冲突及缺失题保留；浏览器验证管理员主流程及手机操作，完成类型检查和构建。
